# Learning Hub

A website with math and physics lessons, videos and worksheets, made by a tutor with more than 15 years of teaching experience. Each topic has its own page where the lesson video and the practice worksheet sit together.

## Who it is for

Middle school, high school and early college students, and the parents who help them, who want clear explanations and practice material in one place.

## What it has today

* A home page with Math and Physics sections
* A page for each subject listing its topics
* A page for each topic with a video area and a worksheet area
* A link to the author's tutoring classes on Outschool

## Built with

* React
* Vite
* React Router

## How to run it

You need Node.js 20 or newer.

1. Clone this repository.
2. Run `npm install`
3. Run `npm run dev`
4. Open the address it prints, usually http://localhost:5173/
